# Simple_C-_Stack_Machine
Hi! I made a code for a simple stack machine in C++.
**How it Works**
Basically, you input two arguments into the terminal when launching the code, the first being a simple .txt file with tab-separated-values (TSV), which is your stack, and the second argument being the .txt file, also with TSV that contains your basic commands like: DIV, ADD, MUL and SUB.
